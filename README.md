# Number Analyzer

A simple command-line tool that collects numbers from the user and performs basic analysis.

## Features

- Separate even and odd numbers
- Find the maximum and minimum value
- Calculate the average

## Usage

```bash
python number_analyzer.py
```

Enter numbers one by one. Enter `0` when done, then choose an operation.
